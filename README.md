
# NUETRON v16 - AI Desktop Assistant

## Run

```bash
pip install -r requirements.txt
set GEMINI_API_KEY="your_key_here"
ollama run llama3.2
python main.py
```

## Commands

- "Neutron, play interstellar soundtrack on youtube"
- "Neutron, do research on quantum computing"
- "Neutron, create a website for a futuristic cyber coffee shop"
- "Neutron, scan screen"
- "Neutron, tell me a story"
